# Витрина организации

Служебный публичный репозиторий организации Roller-Shutter-Systems-Ink. Файл `profile/README.md` показывается на главной странице организации всем посетителям, обложка лежит в `profile/banner.svg`.

## Правила работы

Каждый push сопровождается записью в `JOURNAL.md`: участник или его ИИ-помощник обновляет сводку и добавляет запись о сессии. Без исключений. Правила ведения - в самом журнале.
