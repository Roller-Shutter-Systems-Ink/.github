# Правила для ИИ-помощников

Этот файл читают Codex, Cursor, Claude и другие помощники. Остальные правила репозитория - в `CLAUDE.md`.

## Журнал сессий (обязательно для всех, без исключений)

Журнал проекта - `JOURNAL.md` в корне репозитория. Правило действует для всех, кто работает с проектом, и для их ИИ-помощников (Claude, Codex, Cursor и других).

- В начале работы прочитай в журнале шапку, сводку и последние записи.
- Решения и факты от владельцев проекта, которых нет в документах, записывай в журнал сразу.
- В журнал попадает только то, что относится к проекту: посторонние темы, которые обсуждались в сессии (другие проекты, порядок на компьютере, личные дела), не записываются.
- Перед каждым push обнови журнал по его разделу «Правила ведения журнала»: сводку, решения и запись сессии в конце. Закоммить отдельно: «Журнал: <суть>».
- Push без обновлённого журнала не делай: проверка в CI отмечает его ошибкой.
- Паролей, токенов, персональных данных и личных разговоров в журнале быть не должно.
